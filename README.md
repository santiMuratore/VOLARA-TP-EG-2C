# ✈️ Volara

### Sistema web de gestión, búsqueda y reserva de pasajes aéreos

Volara es un sistema web desarrollado para la gestión y reserva de
pasajes aéreos. El proyecto busca ofrecer una experiencia simple e
intuitiva para la consulta de vuelos y, al mismo tiempo, proporcionar
herramientas de gestión para los distintos perfiles que intervienen
en el sistema.

El proyecto forma parte del **Trabajo Práctico de Entornos Gráficos**.

---

## 📌 Descripción

Volara centraliza las operaciones relacionadas con vuelos y reservas
en una única plataforma web.

El sistema contempla diferentes tipos de usuarios y funcionalidades
según el rol, permitiendo administrar la información necesaria para
el funcionamiento de una plataforma de vuelos.

### 👤 Pasajeros

Los pasajeros podrán utilizar la plataforma para:

- 🔎 Buscar vuelos.
- ✈️ Consultar información de vuelos.
- 🎫 Realizar reservas.
- 📋 Consultar sus reservas.
- 👤 Gestionar su información personal.

### 🏢 Gestión de aerolíneas

El sistema contempla herramientas destinadas a la gestión de
información relacionada con las aerolíneas y sus vuelos.

Entre ellas:

- ✈️ Gestión de vuelos.
- 🏷️ Gestión de promociones.
- 📊 Consulta de información y reportes.
- 📈 Visualización de datos relacionados con la operación.

### 🛠️ Administración

El perfil administrador permite gestionar diferentes aspectos
generales de la plataforma, incluyendo información de usuarios,
aerolíneas y contenido del sistema.

---

## 🚀 Tecnologías

El proyecto está desarrollado utilizando:

| Tecnología | Uso |
|---|---|
| 🐘 **PHP** | Lógica del sistema y procesamiento del servidor |
| 🗄️ **MySQL** | Gestión y almacenamiento de datos |
| 🎨 **Bootstrap** | Diseño y componentes de la interfaz |
| 🌐 **HTML5** | Estructura de las páginas |
| 🎨 **CSS3** | Estilos e identidad visual |
| ⚡ **JavaScript** | Interactividad y funcionalidades del cliente |

---

## 🎨 Identidad del proyecto

**Volara** busca transmitir una identidad moderna, simple y relacionada
con el mundo de los viajes.

La interfaz está pensada para mantener una experiencia visual consistente
en las diferentes secciones del sistema, tanto para pasajeros como para
los perfiles de gestión.
